# ryansworld# Ryan's Financial Knowledge Bot

Ryan is an interactive, Streamlit-powered chatbot that helps users understand basic financial concepts through natural conversation and data visualizations.

## 📦 Features

- 💬 **Conversational Interface** — Ask questions about personal finance, investing, credit scores, etc.
- 📚 **Knowledge Base** — Pulls from mock articles and FAQ entries on financial topics.
- 🧠 **Smart FAQ Matching** — Matches your question to known finance FAQs.
- 📈 **Inflation Trend Chart** — Simulates and plots sample inflation rates over time.
- 💹 **Compound Interest Simulator** — Interactive sliders simulate investment growth.
- 🧾 **Conversation Memory** — Keeps track of chat history during a session.
